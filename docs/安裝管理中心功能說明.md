# Ragnarok 安裝管理中心功能說明

此文件說明 `Install-Manager.ps1` 選單與 `Modules` 資料夾內各腳本的職責。啟動管理中心後，也可以直接輸入 `?` 查看相同的摘要。

## 選單功能

| 選項 | 執行內容 | 是否會改動資料 |
| --- | --- | --- |
| 1 | 安裝或更新 Git、Python、.NET 8、Visual Studio 編譯工具。 | 會安裝或更新 Windows 工具。 |
| 2 | 安裝或修復 MariaDB 資料庫服務。 | 可能修復服務與資料目錄。 |
| 3 | 從 GitHub 下載或更新 rAthena／PandasWS。 | 會更新核心原始碼。 |
| 4 | 使用 Visual Studio 編譯目前核心。 | 會產生伺服器 EXE 與編譯檔。 |
| 5 | 清除目前核心的編譯結果。 | 只移除編譯產物，不刪除資料庫。 |
| 6、D、E | 下載 WARP、英文資源、繁中 NPC 資源。 | 會更新下載資料夾。 |
| F | 將已下載的語言資源套用到客戶端及 rAthena NPC。 | 會覆蓋目標資源檔。 |
| 7 | 建立資料庫並匯入 rAthena SQL。 | 會建立或寫入資料庫。 |
| 8 | 寫入 rAthena 資料庫連線、通訊與 Player Admin 橋接設定。 | 會修改 rAthena 設定及 NPC 腳本。 |
| I | 準備 Player Admin 與專用 .NET 執行環境。 | 會更新管理後台檔案。 |
| J | 啟動 Player Admin 網頁。 | 不下載檔案；只開啟本機管理介面。 |
| C／H | 啟動／停止 rAthena 伺服器。 | 會改變伺服器執行狀態。 |
| B | 移除 Ragnarok 伺服器安裝內容。 | 高風險；必須輸入確認文字才會執行。 |

## Modules 腳本

| 檔案 | 主要功能 |
| --- | --- |
| `Common.ps1` | 共用的管理員權限檢查、外部命令執行、複製檔案與輸入工具。 |
| `Config.ps1` | 讀寫 `Config/installer.json`，保存路徑、資料庫、核心與 Player Admin 設定。 |
| `Environment.ps1` | 安裝或修復開發工具、MariaDB 和其相依元件。 |
| `Git.ps1` | 下載、更新、比對 GitHub 專案，並處理中斷後的 Git 鎖定檔。 |
| `Database.ps1` | 執行 MariaDB 指令，建立遊戲資料庫與匯入 SQL。 |
| `ConfigEditor.ps1` | 寫入 rAthena 的資料庫連線與伺服器設定，建立 Player Admin 的遊戲內橋接功能。 |
| `Compiler.ps1` | 尋找 Visual Studio，編譯或清除 rAthena／PandasWS 的建置結果。 |
| `Localization.ps1` | 將 ROenglishRE 和繁中 NPC 資源套用到正確目錄。 |
| `PlayerAdmin.ps1` | 準備、設定與啟動網頁版玩家管理後台。 |
| `Service.ps1` | 啟動、停止、移除伺服器，以及執行一鍵初始化。 |
| `Logger.ps1` | 將執行訊息和錯誤寫入 `Logs`。 |
| `UI.ps1` | 顯示選單、進度、系統狀態與功能說明。 |
